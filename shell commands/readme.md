open the path in terminal.
To create a file :
vim filename.extension

fill in the contents to the file after pressing I (Insert)
press esc and enter:
:wq (to write and quit)
Save and exit: If you want to save your changes and exit Vim, you can use the :wq command. 
This writes (saves) your changes to the file and then quits Vim. 
Exit without saving: If you don't want to save your changes and just want to exit Vim, you can use the :q!

To make the file as executable :
chmod +x my_script.sh

to execute the file use command :
./my_script.sh


Alternatively we can add the current path to profile and file can be directly executed without above steps
